# ☁️ AWS Static Website Hosting

A modern, responsive static website hosted using **Amazon S3**.  
This project demonstrates how a static website can be deployed to the cloud using AWS S3.

## 🚀 Live Demo

👉 [View Live Website://arnav-cloud-portfolio-2026.s3-website.ap-south-1.amazonaws.com
## 📌 Project Overview

This project demonstrates the deployment of a static HTML, CSS, and JavaScript website using Amazon S3.

The website files are stored in an S3 bucket and configured for public static website hosting.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Amazon S3
- Git & GitHub

## ☁️ AWS Services Used

### Amazon S3

Amazon S3 is used to:

- Store website files
- Host the static website
- Provide public access to website objects
- Serve the website directly through the S3 website endpoint
